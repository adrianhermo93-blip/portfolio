Despliegue con contenedores y pipeline

Aplicación Node.js 20 con Express que cuenta las visitas y las guarda en PostgreSQL. El objetivo era desplegarla como se haría en un entorno real.

Qué hice:

  • Dockerfile para la aplicación y Docker Compose para levantarla junto a la base de datos.
  • Apache configurado como proxy inverso para publicarla en el dominio local adrian.local.
  • Tests automáticos de la lógica de la aplicación.
  • Pipeline de GitHub Actions que descarga el código, instala dependencias, pasa los tests y construye la imagen.

Si los tests fallan, la imagen no se construye, así que nunca se despliega una versión rota.

Node.js Express PostgreSQL Docker Apache GitHub Actions

Entorno web con Docker

Entorno de desarrollo web montado con contenedores en lugar de herramientas tradicionales como XAMPP.

Qué hice:

  • Un contenedor Nginx que recibe las peticiones web.
  • Un contenedor PHP 8.3 que ejecuta el código de la aplicación.
  • Un contenedor MySQL que guarda los datos.
  • Docker Compose para conectar los tres servicios y arrancarlos con un solo comando.

Cada servicio funciona de forma independiente y el entorno se puede reproducir en cualquier equipo que tenga Docker.

Docker Compose Nginx PHP 8.3 MySQL

Clean Code y automatización de pruebas

Proyecto en equipo en Java: partimos de un código con malas prácticas y lo refactorizamos sin romper su funcionamiento.

Qué hice:

  • Detección y corrección de más de 10 code smells, como métodos largos, clases con demasiadas responsabilidades o código duplicado.
  • Aplicación de los principios SOLID, por ejemplo cambiando estructuras switch por polimorfismo.
  • Uso de las herramientas de refactorización de IntelliJ IDEA.
  • Tests automáticos con Selenium WebDriver para comprobar que todo seguía funcionando.

El repositorio guarda la versión original y la refactorizada para comparar el antes y el después.

Java Maven Selenium SOLID IntelliJ IDEA
